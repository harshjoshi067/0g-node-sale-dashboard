# 0G Node Sale Observatory

Interactive dashboard of extracted public Dune data, with charts, searchable tables, filters and CSV exports.

## Run locally

Serve this directory with any static web server and open index.html. No build step or API credentials are required.

## GitHub Pages

In repository Settings > Pages, select Deploy from a branch, then main and / (root).

## Data

Snapshot extracted 27 October 2026. Ten complete query datasets cover 27 of 28 source visualizations. The original cumulative hourly sales-by-tier query fails at its sequence limit. This is historical data, not a live feed.

Source: https://dune.com/node_data/0g-foundation-node-sale

Full data and query definitions are included in 0g-node-sale-data.zip. Onchain buyers are separate from fixed Coinlist and pre-sale inputs. The source uses a fixed USD/wETH conversion. See the ZIP README for details.
